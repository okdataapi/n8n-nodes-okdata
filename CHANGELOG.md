# Changelog

## 0.2.0

First version published to npm (0.1.0 was never published).

- New operations: YouTube Search Videos and Get Video Comments; TikTok Get Video Comments; Instagram Get Profile, Get Posts and Get Post Comments; Reddit Search Posts and Get Post Comments; Amazon Search Products and Get Product Reviews.
- Resources now list TikTok, YouTube, Instagram, X, Reddit and Amazon first, then RedNote (Xiaohongshu), Douyin, WeChat, Weibo and Any Endpoint.
- Any Endpoint > Find can filter by every okdata platform, Amazon, AliExpress, Taobao & Tmall, 1688, Xianyu and Douyin Shop included.
- Messages from okdata now show the details, the next step and the request ID.

## 0.1.0 (never published)

- First release: okdata node with TikTok, RedNote (Xiaohongshu), Douyin, Weibo, WeChat, X and YouTube operations, a free endpoint finder and a call for any okdata endpoint.
- okdata API credential, tested with the free account route.
